LINKKI — Integração de código por e-mail (sem mudanças de estilo)

1. Abra supabase-config.js e substitua os dois valores pelos dados do seu projeto em Supabase > Project Settings > API.
   Use Project URL e Publishable key (ou anon public). NUNCA use service_role ou secret key.
2. No Supabase > Authentication > Email Templates: no template usado para OTP (Magic Link), substitua o link por {{ .Token }}.
   O template Confirm signup também deve usar {{ .Token }} se for utilizado.
3. No Supabase > Authentication > Providers > Email, mantenha o envio por e-mail habilitado.
4. Suba TODOS os arquivos para a raiz do repositório GitHub Pages.
5. Teste cadastro e login com e-mail real. Se a chave não estiver configurada, o site mostra erro e não simula envio.

NOTA: Este pacote conecta cadastro e login por OTP, mas o conteúdo do editor continua salvo localmente no navegador. Sincronização de perfis em banco de dados é uma etapa separada.
